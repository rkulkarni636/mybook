Hover a tile for a quick preview, click to open its article list. On Board opens with Pets / Luggage / Other sub-tabs. Every article links straight to its live page on help.raileurope.com. To add new articles later, edit the CATEGORIES array near the top of this file — see the comment block there.

Editing this page: open the file in any text editor and find the CATEGORIES array in the <script> block. Each category is { title, articles: [{ title, url }] } — add a new object to the articles array to add a page, or a whole new entry to CATEGORIES to add a category. Save and reopen in a browser; no build step needed.

Icon artwork: every tile icon on this page is original vector artwork made for this project — see Image Credits & Sources for the full statement.
